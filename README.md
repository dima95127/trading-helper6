# Trading Helper

Android-приложение для анализа торговых сигналов.

## Сборка APK

1. Загрузите все файлы в репозиторий GitHub (Public)
2. Перейдите во вкладку Actions
3. Дождитесь окончания сборки (30-60 минут)
4. Скачайте артефакт trading-helper-apk

## Возможности

- 8 источников сигналов (RSI, MACD, Bollinger Bands, Stochastic, EMA, Williams %R, ADX, Volume)
- Мартингейл-калькулятор
- График цены
- 14 торговых пар (крипто + форекс)
- 6 таймфреймов
